# SecureLink — اپ اندروید VPN (وایرگارد + IKEv2/IPSec + L2TP)

اپلیکیشن بومی اندروید (Kotlin) برای برقراری اتصال VPN با سه پروتکل:

| پروتکل | موتور | حداقل اندروید |
|---|---|---|
| **WireGuard** | کتابخانه رسمی `wireguard-android` (GoBackend / userspace) نسخه `1.0.20260102` | اندروید ۸+ |
| **IKEv2 / IPSec** | موتور بومی سیستم‌عامل (`VpnManager` + `Ikev2VpnProfile`) | اندروید ۱۱+ |
| **L2TP / PPP** | کلاینت خالص Kotlin (RFC 2661 + PPP) برای سرورهای قدیمی مثل MikroTik | اندروید ۸+ |

امکانات:
- لیست پروفایل‌ها با وضعیت اتصال لحظه‌ای و دکمه اتصال/قطع
- افزودن پروفایل WireGuard با **ایمپورت فایل `.conf`** یا ورود دستی متن کانفیگ
- افزودن پروفایل IKEv2/IPSec با احراز هویت **نام‌کاربری/رمزعبور (EAP-MSCHAPv2)** یا **کلید مشترک (PSK)**
- افزودن پروفایل **L2TP/PPP** با نام‌کاربری/رمزعبور (MS-CHAPv2/v1، CHAP، PAP) — مناسب RouterOS های قدیمی
- رابط کاربری کامل فارسی (RTL) با پشتیبانی ترجمه انگلیسی
- ذخیره‌سازی امن پروفایل‌ها در حافظه داخلی برنامه (JSON)
- جریان مجوز استاندارد VPN اندروید (کادر تأیید سیستم)

## روش ۱ — بیلد APK در گیت‌هاب (بدون نصب هیچ‌چیز)

1. این پوشه را در یک مخزن گیت‌هاب (خصوصی یا عمومی) push کنید:
   ```bash
   cd SecureLink
   git init && git add . && git commit -m "SecureLink initial"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/<REPO>.git
   git push -u origin main
   ```
2. در گیت‌هاب به تب **Actions** بروید؛ workflow به‌محض push اجرا می‌شود
   (یا از دکمه **Run workflow** استفاده کنید).
3. پس از پایان بیلد (۲ تا ۴ دقیقه)، از بخش **Artifacts** فایل
   `SecureLink-APKs` را دانلود کنید؛ شامل هر دو نسخه `debug` و `release` است.
4. فایل APK را به گوشی منتقل و نصب کنید (اجازه «نصب از منابع ناشناس» لازم است).

## روش ۲ — بیلد با Android Studio

1. **Android Studio** (نسخه Ladybug یا جدیدتر، همراه JDK 17) را باز کنید.
2. مسیر **File → Open** و انتخاب پوشه `SecureLink`.
3. صبر کنید تا Sync کامل شود (اینترنت برای دانلود وابستگی‌ها لازم است).
4. از منوی **Build → Build App Bundle(s) / APK(s) → Build APK(s)** اقدام کنید.
5. خروجی: `app/build/outputs/apk/debug/app-debug.apk`

بیلد خط فرمانی (اختیاری):
```bash
./gradlew assembleDebug      # APK دیباگ
./gradlew assembleRelease    # APK ریلیز (با کلید debug امضا شده — قابل نصب)
```

> نکته: نسخه release با کلید debug امضا می‌شود تا بدون تنظیمات اضافه قابل نصب باشد.
> برای انتشار عمومی، keystore اختصاصی بسازید و در `app/build.gradle` جایگزین کنید.

## راهنمای استفاده

### WireGuard
1. دکمه **+** → نوع پروتکل «وایرگارد».
2. **ایمپورت فایل کانفیگ (.conf)** را بزنید و فایل را انتخاب کنید
   (یا متن کانفیگ را دستی در کادر وارد کنید).
3. نام دلخواه بدهید و **ذخیره** کنید.
4. در لیست، دکمه **اتصال** را بزنید؛ کادر مجوز VPN سیستم را تأیید کنید.

نمونه حداقلی کانفیگ:
```ini
[Interface]
PrivateKey = <کلید خصوصی کلاینت>
Address = 10.66.66.2/32, fd42:42:42::2/128
DNS = 1.1.1.1

[Peer]
PublicKey = <کلید عمومی سرور>
Endpoint = vpn.example.com:51820
AllowedIPs = 0.0.0.0/0, ::/0
PersistentKeepalive = 25
```

### IKEv2 / IPSec (اندروید ۱۱ به بالا)
1. دکمه **+** → نوع پروتکل «IKEv2 / IPSec».
2. **آدرس سرور** (دامنه یا IP) و در صورت نیاز **شناسه (Identity)** را وارد کنید.
3. روش احراز هویت را انتخاب کنید:
   - **نام‌کاربری/رمزعبور (EAP)** — سازگار با strongSwan و Cisco
   - **کلید مشترک (PSK)** — رایج در تجهیزات شبکه (مثلاً Mikrotik/IPsec گیت‌وی‌ها)
4. ذخیره و اتصال؛ موتور بومی اندروید اتصال را مدیریت می‌کند
   (کادر مجوز، بار اول نمایش داده می‌شود).

### L2TP / PPP (میکروتیک و سرورهای قدیمی)
1. دکمه **+** → نوع پروتکل «L2TP (میکروتیک قدیمی)».
2. **آدرس سرور** (دامنه یا IP؛ پورت دلخواه با فرمت `host:port`، پیش‌فرض ۱۷۰۱) را وارد کنید.
3. **نام‌کاربری و رمز عبور PPP** (از `/ppp secret` میکروتیک) را وارد کنید.
4. «رمز چالش تانل» فقط برای سرورهایی است که Secret تانل L2TP دارند
   (میکروتیک پیش‌فرض چنین رمزی ندارد — خالی بگذارید).
5. ذخیره و اتصال.

**تنظیم سمت میکروتیک (پیش‌فرض کافی است):**
```
/interface l2tp-server server set enabled=yes use-ipsec=no
/ppp secret add name=user password=pass service=l2tp local-address=10.10.10.1 remote-address=10.10.10.2
```

> ⚠️ **نکته مهم:** این پیاده‌سازی L2TP خالص (بدون IPsec) است؛ احراز هویت با
> MS-CHAPv2 انجام می‌شود اما ترافیک داخل تانل **رمزنگاری نمی‌شود**.
> برای ترافیک حساس از WireGuard یا IKEv2/IPSec استفاده کنید.
> اگر سرور شما `use-ipsec=yes` دارد، یا آن را خاموش کنید یا از پروفایل IKEv2 استفاده کنید.

پشتیبانی احراز هویت: **MS-CHAPv2** (پیش‌فرض میکروتیک)، MS-CHAPv1، CHAP-MD5 و PAP.

## تست اتصال L2TP (بدون نیاز به روتر واقعی)

کلاینت L2TP یک **مجموعه تست یکپارچگی کامل** دارد: کلاینت واقعی (`L2tpClient`) مقابل یک
سرور مجازی MikroTik/xl2tpd (`MockLns`) روی UDP لوکال‌هاست با TUN شبیه‌سازی‌شده اجرا می‌شود:

```bash
# پیش‌نیاز: JDK 17+ و kotlinc (https://github.com/JetBrains/kotlin/releases)
./integration-test/run.sh
```

سناریوها:
- **S1** دست‌دهی کامل (SCCRQ تا IPCP) + MS-CHAPv2 + رفت‌وبرگشت داده + Echo/Hello keepalive + خاموشی تمیز
- **S2/S3** احراز هویت CHAP-MD5 و PAP
- **S4** رگرسیون RFC 2661 §5.8 — پیام واقعی بعد از ZLB باید پردازش شود (باگ قطع‌شدن زودهنگام)
- **S5** رمز تانل (Tunnel Secret)
- **S6** رمز اشتباه → قطع تمیز با خطای 691
- **S7** رفت‌وبرگشت بسته ۱۴۰۰ بایتی (MTU)

تست‌های واحد (کدک سیم + رمزنگاری) هم در CI اجرا می‌شوند: `./gradlew testDebugUnitTest`.
هر دو مجموعه در GitHub Actions به‌صورت خودکار روی هر push اجرا می‌شوند.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| «مجوز VPN تأیید نشده» | دوباره اتصال بزنید و کادر مجوز را OK کنید |
| IKEv2 غیرفعال/خطای نسخه | IKEv2 فقط روی اندروید ۱۱+ کار می‌کند؛ برای دستگاه‌های قدیمی‌تر از WireGuard استفاده کنید |
| خطای Sync در Android Studio | JDK 17 انتخاب شده باشد (Settings → Build Tools → Gradle)؛ اینترنت فعال باشد |
| وایرگارد وصل نمی‌شود | `Endpoint`، `PrivateKey` و `PublicKey` را بررسی کنید؛ دیوارآتش سرور پورت UDP را باز گذاشته باشد |
| L2TP می‌گوید سرور پاسخ نمی‌دهد | `enabled=yes` و `use-ipsec=no` در `/interface l2tp-server server` باشد؛ پورت UDP ۱۷۰۱ باز باشد |
| L2TP خطای احراز هویت ۶۹۱ | نام‌کاربری/رمز `/ppp secret` غلط است یا `service=l2tp` تعریف نشده |
| L2TP وصل شد ولی اینترنت ندارد | DNS و مسیر پیش‌فرض سمت سرور (`local-address`، پروفایل PPP) را بررسی کنید؛ سرور باید IP از `remote-address pool` بدهد |
| اتصال وایرگارد پس از بستن اپ قطع می‌شود؟ | خیر؛ تانل در سرویس پیش‌زمینه سیستم اجرا می‌شود. برای Always-on: تنظیمات → شبکه → VPN → آیکون چرخ‌دنده → Always-on |

### گزارش عیب‌یابی داخل برنامه (نسخه ۱.۰.۲ به بالا)

اگر اتصال (مخصوصاً L2TP) مدام قطع می‌شود، بدون نیاز به کامپیوتر می‌توانید علت را ببینید:

1. در صفحه اصلی، دکمه **«گزارش عیب‌یابی»** را بزنید.
2. اتصال را برقرار کنید و صبر کنید تا قطع شود — زمان و علت قطع‌شدن با مُهر زمانی ثبت می‌شود.
3. با دکمه **«ارسال»** متن گزارش را برای بررسی بفرستید (یا با «کپی» کپی کنید).

جمع با گزارش برنامه، لاگ سمت **سرور MikroTik** هم بسیار کمک می‌کند:
```
/log print follow-only where topics~"l2tp"
```
و لاگ کامل اندروید در صورت دسترسی به کامپیوتر:
```
adb logcat -s SecureLink-L2TP SecureLink-L2TP-Svc
```

## نکات امنیتی
- کانفیگ‌ها و رمزها فقط در حافظه داخلی برنامه (sandbox اندروید) ذخیره می‌شوند.
- این پروژه هیچ سرور یا سرویس واسطی ندارد؛ فقط به سرورهای خودتان وصل می‌شود.
- موتور WireGuard همین کتابخانه رسمی‌ای است که اپ رسمی WireGuard استفاده می‌کند.
